# Ciao, Mars! — One-page restaurant website

A responsive, single-page website concept for an Italian-Filipino restaurant. Built with plain HTML, CSS, and vanilla JavaScript — no build step, package manager, or framework required.

## Preview locally
1. Unzip the project.
2. Open `index.html` in a browser.

For a local server, you can also use VS Code's Live Server extension, or run `python -m http.server` from this folder.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Included
- Responsive mobile navigation
- Menu filters for Italian classics, Filipino favorites, fusion dishes, and desserts/drinks
- Tap-to-call phone link and Instagram link
- Opening hours: 10:00 AM–10:00 PM
- Accessible labels, reduced-motion support, and semantic sections

## Before launch
- Menu names, descriptions, and prices are illustrative concept content; verify them before publishing.
- Restaurant location and reservation details are not supplied and are marked as coming soon.
- Food photography and Google Fonts load from external URLs, so an internet connection is needed for those assets.
- Confirm image licensing and replace any image URLs with photos you own or are licensed to use.
- Update contact details and any operational information as needed.
